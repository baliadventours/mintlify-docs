Tripbone handles the technical SEO work that helps travelers find your tours on Google. The platform auto-generates meta titles, descriptions, structured data markup, dynamic sitemaps, and clean URLs for every page. You do not need to install plugins or edit code to rank well in search results.

## Metadata autopilot

For every tour and blog post, Tripbone generates an optimized meta title and description using Google Gemini AI. The AI pulls from your tour highlights, destination, and tone settings to create search-friendly snippets that encourage clicks.

You can review and override any meta tag from the page editor. If you leave the fields blank, the AI keeps them updated automatically as your content changes.

## JSON-LD Schema for rich results

Tripbone injects schema.org JSON-LD markup on every tour page. This structured data tells Google to display rich results such as star ratings, pricing, and availability directly in search listings. Rich results increase visibility and click-through rate without any extra work on your part.

The markup includes:

- Tour name and description
- Aggregate rating from guest reviews
- Price and currency
- Availability status
- Organizer name and URL

## Dynamic sitemap

Your XML sitemap updates automatically every time you publish a new tour, blog post, or page. Search engines are notified of new content immediately, which speeds up indexing. You can view and manually submit your sitemap from **Content \> SEO Tools \> Sitemap**.

## Robots.txt management

Tripbone generates and hosts a robots.txt file that guides search engine crawlers. You can allow or disallow specific paths from **Content \> SEO Tools \> Robots.txt**. This is useful if you want to hide draft pages or internal tools from search results.

## Redirect engine for slug changes

If you change a tour or blog post URL, Tripbone automatically creates a 301 redirect from the old slug to the new one. This preserves your search rankings and prevents broken links. You can also create manual redirects from **Content \> SEO Tools \> Redirects**.

<Warning>
  Manually editing robots.txt or creating wildcard redirects can affect your search visibility. Test changes in a staging environment before applying them to your live site.
</Warning>
