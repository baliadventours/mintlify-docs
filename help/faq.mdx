If you are considering Tripbone or have just started using it, this page covers the questions we hear most often from tour operators, travel agencies, and independent guides.

<Accordion title="Do I need to be a tech person to use Tripbone?">
  No. Tripbone is built for tour operators, not developers. The dashboard is point-and-click, and the AI tools handle complex tasks like writing tour descriptions and extracting booking data from emails. If you can use email and a spreadsheet, you can run Tripbone. For users who want a fully hands-off setup, the System \+ Installation plan includes white-glove server configuration.
</Accordion>

<Accordion title="Where is my data hosted?">
  Tripbone runs on Firebase and Google Cloud, which means your data is stored in Google-grade secure data centers with automatic encryption, redundancy, and global availability. You do not need to manage servers, patches, or backups yourself. The 1-click backup tool in Settings lets you download a full snapshot of your data at any time.
</Accordion>

<Accordion title="Is it really zero commission?">
  Yes. Tripbone is a one-time purchase, not a subscription. You pay once for the system, and you keep 100% of every booking. There are no per-transaction fees, no monthly charges, and no hidden commissions. The only fees you pay are to your payment gateway (e.g., Stripe or PayPal), which is standard for any online business.
</Accordion>

<Accordion title="Can I use my own domain?">
  Yes. You can map your storefront to any domain you own, such as `tours.yourbrand.com` or `bookings.yourcompany.com`. Domain mapping is included in the System \+ Installation plan and above. You will need access to your domain registrar to update DNS records, and Tripbone provides step-by-step instructions.
</Accordion>

<Accordion title="Does it work on mobile?">
  Yes. Your Tripbone storefront is fully responsive, which means guests can browse tours, check availability, and complete bookings from any phone or tablet. The admin dashboard is also mobile-friendly, so you can manage bookings and check your profit dashboard on the go.
</Accordion>

<Accordion title="What if I have 500 existing tours on another site?">
  Tripbone includes an inventory migration tool. On the System \+ Installation plan, we migrate up to 10 tours for you as part of the setup. For larger catalogs, the Enterprise plan includes bulk migration services. You can also add tours manually using the AI Tour Writer, which generates full descriptions from a few bullet points.
</Accordion>

<Accordion title="Can I have multiple currencies?">
  Yes. You can set your primary currency in Settings and display prices in additional currencies for international guests. Exchange rates can be updated manually or synced automatically. Your payment gateway will still settle in your primary currency.
</Accordion>

<Accordion title="What support is included?">
  All plans include access to community support documentation. The System \+ Installation plan adds a direct support line for setup questions. Enterprise plans include a dedicated success manager, priority response times, and staff training sessions.
</Accordion>

<Accordion title="Can I add staff accounts?">
  Yes. Tripbone supports four user roles: Super Admin, Operations Manager, Staff/Agent, and Supplier/Vendor. You can invite unlimited team members and control exactly what each person can see and edit. Only Super Admins can access billing and system-level settings.
</Accordion>
